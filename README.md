# PAIP research

PAIP（Personal AI Interoperability Protocol）は、異なる所有者が管理する個人AI同士で、メッセージ・委任された権限・失効・操作結果を交換するときに、双方が証拠の意味を同じように解釈できるかを調べる個人研究です。

この研究は、設計の正しさを主張するために公開しているのではありません。**成立しない条件を見つけてもらうため**に公開しています。
